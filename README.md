# Akashic Wealth website

Static site generated by one Python script, served by a Cloudflare Worker with a D1 database for link tracking and event signups.

## Files

- `build_pages.py`: every page's copy, links, FAQ, events and legal text. Run it to generate the HTML and `dist/`.
- `akashic.css`, `akashic.js`, `hero.js`: styles, page behaviour, the WebGL hero.
- `worker.js`, `wrangler.toml`, `schema.sql`: the Worker, its config, the two tables.
- `assets/`: hero textures, logo, favicon, self-hosted fonts, Discord screenshots (`assets/peek/`).

The HTML files and `dist/` are generated. Do not hand-edit them.

## Build and preview

```
python build_pages.py
cd dist && python -m http.server 8811
```

Open http://127.0.0.1:8811/. The hero needs HTTP, not `file://`. To preview signups and stats too: `npx wrangler d1 execute akashic-stats --local --file schema.sql`, then `npx wrangler dev`.

## Deploy on your Cloudflare account

```
npx wrangler login
npx wrangler d1 create akashic-stats        # paste the id into wrangler.toml
npx wrangler d1 execute akashic-stats --remote --file schema.sql
npx wrangler secret put STATS_KEY           # a long random string; never put it in a file
python build_pages.py
npx wrangler deploy
```

Check: `/` and `/events` load, `/stats?key=KEY` shows tables, a form submit shows up in `/signups.csv?key=KEY`. For a real domain, add it to Cloudflare, set `workers_dev = false`, uncomment `routes` with your hostname, deploy again. The edge can serve the old version for a few minutes after a deploy.

## Editing

All in `build_pages.py`:

- `WHOP`, `DISCORD`: the Join link and the invite. The invite must be permanent; check `https://discord.com/api/v10/invites/CODE?with_expiration=true` returns `expires_at: null`.
- `EVENTS`: the class. `meta` is the one place a date belongs. Add the time there.
- FAQ, feature cards, membership plate, About: search the visible text and edit in place.
- `terms_blocks`, `privacy_blocks`, `risk_blocks`: legal pages. Read HANDOFF.md first.
- `PEEK`: the proof section. Twelve member cards (`assets/peek/m01..m12.webp`, about 500 px wide), the recap in two halves (`recap-a/b.webp`, about 680 px wide), the Bill and Kevin captures.

## Tracker and signups

- `/anything` that is not a page, or `/go/anything`, logs a hit for that tag and redirects home. Home logs as `direct` or `?src=`. One tag per post or bio link.
- Hits store time, tag, country, region, city, referrer, user agent. Signups store time, event, email, country. No IP, no cookies. The privacy policy says so; keep it true.
- Google Sheet: `=IMPORTDATA("https://YOUR-DOMAIN/signups.csv?key=KEY")` in A1. Refreshes about hourly. On `#REF!`, click the cell, F2, Enter. The key is visible to anyone who can open the sheet.

## Rules from the owners

- No dates in copy except the event `meta`.
- No motion that follows the pointer. Hover on buttons is a lighter gradient, nothing more. The carousel never snaps back.
- Cormorant Garamond for display type. Fonts stay self-hosted. No third-party script, font, pixel or analytics without updating the privacy policy.
- Join always goes to the Whop monthly product.
- The results disclaimer and the risk language stay.

## Gotchas

- A narrow headless window falsely shows right-edge clipping. Use real mobile emulation.
- For a full-page home screenshot, inject `<style>.hero{min-height:0!important;padding:40px 0!important}#hero-canvas{display:none}</style>` into a temp copy of `index.html`. The headline fades in four seconds after load.
- Hero timing is the constants at the top of `hero.js`.
- Cormorant's old-style numerals turn `0DTE` into `oDTE`; use `font-variant-numeric: lining-nums` where numerals sit in it.
